# plugin-stubs

Type stubs for [Plugin](https://github.com/Caylies/Plugin).

`plugin-stubs` provides type information for Plugin, making it easier to develop plugins with type checkers such as Pyright.

## Installation

> [!TIP]
> Installing `plugin-stubs` with the `all` extra is recommended. This also installs the dependencies required for complete type information, including types from Ballsdex.

Using [uv](https://docs.astral.sh/uv/):

```bash
uv add "plugin-stubs[all] @ git+https://github.com/Caylies/plugin-stubs@1.0.1"
```
